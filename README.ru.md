# xv6 — что происходит под капотом

Мои лабораторные работы по операционным системам в **FEI STU** на основе **учебной ОС xv6 для RISC-V**.

Указатели и структуры в C стали намного понятнее, когда я изучил устройство памяти. Эти лабораторные позволяют исследовать связанные темы внутри небольшой операционной системы: процессы, системные вызовы, таблицы страниц и ловушки.

Задания веду на [GitLab](https://gitlab.com/ilushkalubotin/xv6-xliubotin-2026). Эта копия на GitHub объединяет их с остальными проектами и сохраняет существующую историю веток.

## Обзор лабораторных

Каждая ветка — отдельный снимок задания. Таблица описывает работу, представленную в импортированной истории.

| Ветка | Тема |
| --- | --- |
| [util](https://github.com/ZakaGreen/xv6-labs-2026/tree/util) | Утилиты пользовательского пространства, процессы и каналы. |
| [syscall](https://github.com/ZakaGreen/xv6-labs-2026/tree/syscall) | Системные вызовы, в том числе их перехват и задания с песочницей. |
| [pgtbl](https://github.com/ZakaGreen/xv6-labs-2026/tree/pgtbl) | Таблицы страниц и память процессов. |
| [traps](https://github.com/ZakaGreen/xv6-labs-2026/tree/traps) | Вывод стека вызовов ядра, `sigalarm` и `sigreturn`. |
| [lock](https://github.com/ZakaGreen/xv6-labs-2026/tree/lock) | Начатая и пока незавершённая лабораторная по блокировкам. |

Ветка `main` добавляет это описание к снимку `util`. Пять лабораторных веток сохраняют оригинальные коммиты. Это копия состояния GitLab на момент публикации, без автоматической синхронизации.

## Локальное изучение

```bash
git clone https://github.com/ZakaGreen/xv6-labs-2026.git
cd xv6-labs-2026
git switch util
make qemu
```

Для сборки нужны подходящий набор инструментов RISC-V и QEMU с поддержкой RISC-V. Ссылки на инструменты находятся в исходном [README проекта xv6](README). При выборе ветки и запуске проверок следуйте соответствующему заданию. Сборка и проверочные тесты лабораторных при переносе в портфолио повторно не запускались.
